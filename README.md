SENTRA – AI Software Reliability Engineer

An intelligent software reliability monitoring project built using Python. SENTRA monitors website and API health, checks HTTP status codes, measures response time, and identifies connection errors.

🚀 Features

- Website Health Monitoring
- API Monitoring
- HTTP Status Code Detection
- Response Time Measurement
- Health Status Reporting
- Error Detection and Alerts
- API Response Data Display

🛠️ Technologies Used

- Python
- urllib.request
- time
- REST API
- GitHub

📂 Project Structure

- "Main.py" – Website Health Monitoring
- "API_Monitor.py" – API Monitoring
- "README.md" – Project Documentation

▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the Python files in a Python IDE.
4. Run "Main.py" to monitor a website.
5. Run "API_Monitor.py" to monitor an API.
6. Enter a valid website or API URL.
